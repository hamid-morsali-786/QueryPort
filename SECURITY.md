# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within **QueryPort**, please do not open a public issue.
Instead, report it directly to the maintainer via email or GitHub Security Advisory:

- **Maintainer**: Hamid Morsali
- **GitHub**: [@hamid-morsali-786](https://github.com/hamid-morsali-786)

Please provide detailed information regarding the vulnerability, reproduction steps, and potential mitigation if known.
We will respond promptly and issue a security fix in a timely manner.
